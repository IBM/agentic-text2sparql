# Text-to-SPARQL Demo Output

This directory contains the output generated by `src/run_text2sparql.py` for
question `112` from the English no-mentions development questions.

## Question

> Which movie released in the last ten years has won the most Academy Awards?

## Command

The files were generated with:

```bash
uv run python src/run_text2sparql.py \
  --input data/en_no_mentions_dev_questions.json \
  --split dev \
  --question-ids 112 \
  --output-dir outputs/demo/ \
  --parallel 1
```

`--parallel 1` processes the selected question sequentially. The runner uses
the `dev` split name in the output filenames, so the artifacts are prefixed
with `dev_112`.

## Files

### `dev_112_answer.json`

The extracted final answer as a JSON array containing Wikidata identifiers.
The generated answer is:

```json
[
  "Q20856802"
]
```

`Q20856802` is the Wikidata item for **La La Land**.

### `dev_112_sparql.json`

The final SPARQL query selected by the agent, stored as a JSON object under
the `sparql` key. It uses the following Wikidata properties and entities:

- `P577`: publication or release date
- `P166`: award received
- `Q11424`: film
- `Q19020`: Academy Awards
- `P31` and `P279`: type and subclass paths used to identify films and Academy Awards

The query limits the result to films released during the last ten-year window,
counts distinct Academy Award categories linked to each film, orders films by
that count, and identifies `Q20856802` with six wins as the top result. The
query saved in this file is a follow-up query that retrieves the selected
film, its release dates, and its associated Academy Award categories.

### `dev_112_session.log`

The complete OpenCode session export in machine-readable JSON format. It
includes session metadata, the prompt, agent messages, tool calls, Wikidata
searches, SPARQL executions, and their results. Use this file when the full
structured execution record is needed for analysis or programmatic processing.

### `dev_112_session.trace.md`

The same session rendered as a human-readable Markdown trace. It shows the
pipeline steps in order, including entity and property searches, graph
exploration, candidate query execution, query refinement, and the final JSON
answer. The trace is useful for reviewing how the answer and query were
produced without parsing the session export.

## Result Summary

The agent resolved the answer to:

- **Movie:** La La Land
- **Wikidata ID:** `Q20856802`
- **Recorded Academy Award wins:** 6

The generated artifacts reflect the Wikidata data and query execution at the
time the command was run. Results may change as Wikidata is updated.
